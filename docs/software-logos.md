# Software logos

These marks are bundled for the version selector. Each file is kept in its supplied colors and proportions.

| Mark | Source |
| --- | --- |
| Paper | [PaperMC brand assets](https://docs.papermc.io/misc/assets/) |
| Purpur | [Purpur website](https://purpurmc.org/images/purpur.svg) |
| Fabric | [Fabric website](https://fabricmc.net/assets/logo.png) |
| Velocity | [PaperMC brand assets](https://docs.papermc.io/misc/assets/) |
| Forge | [Minecraft Forge website](https://files.minecraftforge.net/static/images/logo.svg) |
| NeoForge | [NeoForged art assets](https://github.com/neoforged/.github/tree/main/art), licensed CC BY 4.0 |

PaperMC's logo use guidelines prohibit recoloring, changing dimensions, or creating derivatives. Obsidian uses the provided asset as an image without changing its colors. Product marks identify the software and do not imply endorsement.

The NeoForged icon is included unchanged. The team requests attribution under CC BY 4.0; this page identifies NeoForged as its source.
